# Precursor purity checker

:material-menu-open: **Feature list methods → Processing → Precursor purity checker (purity)**

!!! info "Documentation in progress"

    We are currently working on the documentation for this module. Until it is available, the
    parameter descriptions are shown as tooltips in the module's parameter dialog in mzmine.

## Description

Checks, for each MS2 spectrum, the corresponding MS1 spectrum to find out whether the precursor isolation was chimeric. The purity is calculated as the main signal intensity divided by the total signal intensity.
