# Average formulas for ion identities

:material-menu-open: **Feature list methods → Feature grouping → Average formulas for ion identities**

!!! info "Documentation in progress"

    We are currently working on the documentation for this module. Until it is available, the
    parameter descriptions are shown as tooltips in the module's parameter dialog in mzmine.

## Description

Creates a list of average molecular formulas from all formula lists of all ions in a network (e.g., M+H and M+Na).
