# Annotate possible isomers

:material-menu-open: **Feature list methods → Feature grouping → Annotate possible isomers**

!!! info "Documentation in progress"

    We are currently working on the documentation for this module. Until it is available, the
    parameter descriptions are shown as tooltips in the module's parameter dialog in mzmine.

## Description

Annotates features with the same (or similar) _m/z_ but different mobilities within a specified retention time window.
